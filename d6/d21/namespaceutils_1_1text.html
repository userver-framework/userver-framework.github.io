Removes double quotes from front and back of string.

Examples:

RemoveQuotes("\"test\"") // returns "test"
RemoveQuotes("\"test") // returns "\"test"
RemoveQuotes("'test'") // returns "'test'"
RemoveQuotes("\"\"test\"\"") // returns "\"test\""
