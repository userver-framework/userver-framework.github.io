143 /// The core method for HTTP request handling, that is used only if @ref IsStreamed() returned `true`.
144 /// `request` arg contains HTTP headers, full body, etc.
145 /// The response body is passed in parts to `ResponseBodyStream`.
146 /// Stream transmission is useful when:
147 /// 1) The body size is unknown beforehand.
148 /// 2) The client may take advantage of early body transmission (e.g. a Web Browser may start rendering the HTML
149 /// page or downloading dependent resources).
150 /// 3) The body size is huge and we want to have only a part of it in memory.
151 ///
