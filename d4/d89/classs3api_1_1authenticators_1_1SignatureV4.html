Detailed Description

Authenticator implementing AWS Signature Version 4.

Auth signs a request with headers (Authorization, X-Amz-Date, X-Amz-Content-Sha256), Sign produces query parameters for a presigned URL (X-Amz-Algorithm, X-Amz-Credential, X-Amz-Date, X-Amz-Expires, X-Amz-SignedHeaders, X-Amz-Signature).

See https://docs.aws.amazon.com/AmazonS3/latest/API/sig-v4-authenticating-requests.html
