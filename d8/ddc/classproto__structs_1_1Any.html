◆ operator==()

bool proto_structs::Any::operator== ( const Any & ) const
delete

Any is not comparable, because same values may have different binary representations (e.g. for an integral field explicitly writing out 0 and not writing the field result in the same value), and unpacking the value would be too heavy for operator== and could result in an "unknown type" error.
