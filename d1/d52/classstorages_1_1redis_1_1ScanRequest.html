template<ScanTag TScanTag>
class storages::redis::ScanRequest< TScanTag >

Redis future for a SCAN-like responses.

Member functions of classes storages::redis::Client and storages::redis::Transaction that do send SCAN-like request to the Redis return this type or storages::redis::ScanRequest.
