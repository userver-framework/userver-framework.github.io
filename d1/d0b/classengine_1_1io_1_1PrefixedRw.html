Detailed Description

engine::io::RwBase adapter that returns a fixed byte prefix before reading from the underlying stream.

Useful when some already-received bytes must be replayed as if they were still unread on the socket (for example, handshake leftovers buffered by a third-party library).

Writes always go to the underlying stream. The readable awaitable reports ready while unread prefix bytes remain (so engine::WaitAny wakes even if the underlying socket has no data yet); afterwards it follows the underlying stream.

auto underlying = std::make_unique<MemoryRwBase>("world");
engine::io::PrefixedRw stream("hello-", std::move(underlying));
std::array<char, 32> buf{};
ASSERT_EQ(11, stream.ReadAll(buf.data(), 11, {}));
EXPECT_EQ(std::string_view(buf.data(), 11), "hello-world");
