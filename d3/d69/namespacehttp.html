◆ UrlEncodePathSegment()

std::string http::UrlEncodePathSegment ( std::string_view input_string)

Encode a URL path segment (for use in S3 and similar APIs).

Parameters
input_stringString to encode
Returns
URL-encoded string where special characters are encoded as XX sequences, but path-safe characters (-, _, ., ~, $, &, ,, :, =, ) are kept unescaped
Note
This is less aggressive than UrlEncode and is suitable for encoding path segments where you want to preserve readability of certain special characters
auto encoded = UrlEncodePathSegment("file-name_with spaces.txt");
EXPECT_EQ(encoded, "file-name_with%20spaces.txt");
