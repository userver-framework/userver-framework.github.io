POSTGRES_TOPOLOGY_SETTINGS Dynamic Config

Dynamic config that controls topology settings of service's PostgreSQL components.

Dictionary keys can be either the value of name_alias static configuration option of the PostgreSQL component (not database name!) or __default__. The latter configuration is applied for every non-matching PostgreSQL component of the service.

Take note that it overrides the static configuration values of the service!

Schema:

Dynamic config that controls topology settings of service's PostgreSQL
components.
Dictionary keys can be either the value of `name_alias` static configuration option of the PostgreSQL component

Take note that it overrides the static configuration values of the service!
